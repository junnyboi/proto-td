# Accepted Concept Reference Findings

The existing **Mission Command** concept establishes the correct landscape density for Protos: full-viewport composition, three large adult-operator cards as the emotional focus, cyan selected states, a compact right-side squad and loadout inspector, and a persistent bottom action dock. Its strongest reusable traits are the thin antique-gold technical linework, clipped corners, black-blue glass, readable ivory typography, and cyan energy used only for state and priority. Existing mission features—mission intelligence, squad capacity, selected identities, loadout readiness, training route, back navigation, and deployment—are all visibly integrated rather than treated as decoration.

The existing **Recruit Training** concept establishes the preferred dossier pattern: a compact roster rail, one large selected adult operator portrait, a focused progression inspector, contextual return navigation, and three persistent actions. It uses portrait art to provide gacha appeal without reducing the interface to a gallery. Promotion readiness, XP, class paths, permanence messaging, and return-to-mission continuity remain visible. Together, these concepts define the target system for the broader revamp: character-forward editorial asymmetry, ceremonial lunar machinery, native functional data, tight angular surfaces, and no generic centered utility dialogs.
