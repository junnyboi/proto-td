# Collaboration Plans

Store concise repository-local contracts needed by another agent to resume or integrate work. Plans support execution; completion still requires runtime gates and evidence.

Prefer filenames `TD-###-short-topic.md`; established domain IDs may retain their names. Every plan includes:

- goal, observable/player-facing outcome, and explicit non-goals;
- pinned base SHA, branch, owner, exclusive files, and forbidden files;
- observable dependency contracts rather than promised line numbers;
- file-level deliverables and ordered implementation sequence;
- falsifiable acceptance criteria and named verification evidence;
- trim order, never-cut items, assumptions, and numbered deviation candidates;
- handoff and integration responsibilities.

Canonical large phase plans live in the Manus MGS project knowledge area. Mirror only the actionable collaboration contract here; do not fork or silently supersede the canonical plan. For gameplay work, derive exactness tests on paper, pin tick-observation conventions, and run MGS reviewer preflight before implementation. Every plan terminates in machine gates plus a human-playtestable state.
